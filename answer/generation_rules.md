## 1. 심어둔 이슈

| 퍼널 구간 | 이슈 | 데이터에 남길 행동 신호 | 크기 | 처리 |
|---|---|---|---|---|
| 장바구니 → 주문서 | 무료배송 기준 금액(3만 원)을 채울 상품을 찾으러 나갔다가 이탈 | 장바구니 → 탐색 이동 후 미복귀, 이탈 직전 조회 상품 가격이 부족 금액 근처에 몰림, 부족 금액 3천~8천 원 구간에서 이탈 집중 | **대** | **A/B 테스트** |
| 상품 상세 → 장바구니 | 색조 상품의 호수·컬러 선택 어려움 | 옵션 선택창 반복 열람, 리뷰 탭 장시간 체류, 옵션 불만 교환·반품 | 중 | 백로그 |

- 우선순위 판단 근거: 장바구니 이슈는 전 카테고리·신규 첫 구매에 영향, 호수 이슈는 색조 카테고리(매출 20%)에 한정

## 2. 고객 세그먼트

- 기준: 채널 무관, 구매 이력이 한 번이라도 있으면 기존 고객

| 구분 | 세그먼트 | 정의 | 장바구니 특성 | 첫 온라인 구매 후 재구매 |
|---|---|---|---|---|
| 기존 | 온라인 이용 고객 | 온라인 구매 이력 있음 | 자주 사던 소모품을 바로 담아 기준을 채움 → 이탈 낮음 | — |
| 기존 | 매장 전용 고객 | 매장 구매만 있음 | 매장에서 낱개로 사던 습관 → 첫 온라인 장바구니가 작음 | 낮음 (매장으로 돌아감) |
| 신규 | 신규 고객 | 구매 이력 없음 | 써보려고 1~2개만 담음 → 기준 미달 많음, 무엇을 더 담을지 모름 | 높음 (온라인이 주 채널) |

### 함정 1: 기존 고객 평균에 숨은 문제

- 기존 고객 전체의 장바구니 전환율은 정상으로 보이지만, 매장 전용 고객만 떼어보면 신규와 비슷한 이탈 패턴
- 분석가는 고객 유형보다 **"장바구니 금액이 기준 미달인가"**가 이탈의 핵심 원인임을 찾아야 함

### 함정 2: 상관관계

- 사전 데이터에서 "장바구니에서 상품을 추가로 담은 고객의 전환율이 높음"이 보임
- 그러나 원래 살 마음이 큰 고객이 추가로 담은 것 → 추천을 보여주면 전환이 오른다는 근거가 아님 → A/B가 필요한 이유

## 3. KPI 트리상 정답

| 칸 | 정답 |
|---|---|
| 기존 고객 매출 | 목표 수준 유지 |
| 신규 방문·가입 수 | 마케팅 확대로 증가 |
| 신규 첫 구매 전환율 | 하락 |

- 원인: 신규의 첫 장바구니 금액이 작아 무료배송 기준 미달 비율이 높고, 미달 상태에서 금액을 채우러 나갔다가 이탈
- 무료배송 기준 상향(올해 초, 2만 → 3만 원)으로 신규의 작은 첫 장바구니가 기준 미달이 되는 비율 증가
  → 전년 대비 신규 첫 구매 전환율 하락의 주요 원인
- 기존 고객은 원래 장바구니가 커서 영향이 작음

### 월별 KPI 집계에 심을 패턴

| 지표 | 패턴 |
|---|---|
| 신규 방문·가입 수 | 마케팅 확대 이후 증가 |
| 신규 첫 구매 전환율 | 기준 상향 시점 직후 계단식 하락, 이후 회복 없음 |
| 기존 고객 구매 전환율 | 기준 상향 전후 큰 변화 없음 |
| 신규 첫 주문 평균 금액 | 기준 상향 이후 소폭 증가 (기준을 넘긴 고객만 남은 생존 편향) |

## 4. A/B 테스트

### 실험 구성

| 군 | 장바구니 하단 |
|---|---|
| A (대조군) | 추천 없음 |
| B | 부족 금액에 맞는 상품 추천 (가격대 = 부족 금액 ~ 부족 금액 + α, 소모품·미니 사이즈 위주) |
| C | 부족 금액에 맞는 상품 + 최근 조회 카테고리 기반 관심 상품 추천 |

- 대상: 장바구니 금액이 무료배송 기준 미만인 상태로 장바구니에 진입한 고객
- 배정: 고객 단위, 해당 상태로 장바구니에 처음 진입한 시점에 1:1:1

### 심어둘 결과

| 관점 | 결과 |
|---|---|
| 전체 전환율 | A < B < C |
| 세그먼트 | 효과 크기: 신규 > 매장 전용 > 온라인 이용 |
| B vs C (세그먼트별) | 온라인 이용 고객은 C가 B보다 확실히 높음 (조회 이력이 많아 관심 상품이 정확함). **신규는 C ≈ B** (조회 이력이 적어 관심 상품 추천이 부정확, 콜드 스타트) |
| 객단가 | B·C 모두 증가, C가 더 큼 (관심 상품은 단가가 더 높음) |
| 배송비 수익 | B·C 모두 감소 (원래 배송비를 내고 샀을 고객이 기준을 넘김) |
| 반품률 | B만 소폭 증가 (금액 맞추려고 담은 저가 상품) |
| 공헌이익 | **B는 거의 변화 없거나 소폭 감소, C는 증가** |
| 재구매 | 신규는 첫 구매 후 재구매 높음, 매장 전용 고객은 낮음 |

### 의도한 의사결정 포인트

- 전환율만 보면 B도 성공이지만, 배송비 수익 감소·저가 상품 반품을 반영한 공헌이익으로는 C만 의미 있음
- 신규 고객에게는 관심 상품 추천이 작동하지 않음 (콜드 스타트) → 신규에게는 인기 상품 등 다른 대안이 필요하다는 후속 과제
- 결론 방향: C 출시, 신규 고객용 추천 로직은 후속 실험

- 구체적 효과 크기는 실험 설계서의 MDE·표본 크기 확정 후 결정
