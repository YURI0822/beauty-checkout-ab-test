# 01. 도메인 설정서

##  1. 플랫폼 개요

| 항목 | 내용 |
|---|---|
| 플랫폼명 | 데일리글로우 (DAILY GLOW) , 가상 플랫폼 |
| 이름의 의미 | 매일 쓰는 생활 및 뷰티 소모품으로 매일의 나를 빛나게 하는 플랫폼 |
| 업종 | H&B (헬스 & 뷰티) 옴니채널 리테일 |
| 판매 채널 | 오프라인 매장 + 온라인(앱·모바일 웹) |
| 주요 카테고리 | 스킨케어, 색조, 헤어·바디, 위생용품, 건강기능식품 |
| 회원 체계 | 매장·온라인 공통 멤버십 (매장 구매도 멤버십 적립으로 회원 식별 가능), 온라인 구매는 회원만 가능 |

- 생활 소모품 중심 → 재구매 주기가 짧은 구조
- 매장과 온라인이 하나의 멤버십으로 연결됨
  
## 2. 고객 구분 기준 (사내 공통)

| 구분 | 정의 |
|---|---|
| 기존 고객 | 채널(매장·온라인) 관계없이 구매 이력이 1회 이상 있는 회원 |
| 신규 고객 | 매장·온라인 모두 구매 이력이 없는 회원 |

- 가입일이 아니라 구매 이력 기준
- 경영 리포트의 '기존/신규 고객 매출'도 이 기준으로 집계

## 3. 사업 규모 
| 항목 | 수치 |
|---|---|
| 연 매출 | 약 1.2조 원 |
| 온라인 매출 비중 | 약 25% (연 약 3,000억 원) |
| 매장 수 | 약 800개 |
| 멤버십 회원 수 | 약 1,200만 명 |
| 앱 MAU / DAU | 약 600만 명 / 약 80만 명 |
| 월 온라인 주문 수 | 약 55만 건 |
| 온라인 접속 비중 | 앱 80% / 모바일 웹 20% |


## 4. 수익 구조

| 항목 | 내용 |
|---|---|
| 채널별 객단가 | 매장 약 2.3만 원 / 온라인 약 4.5만 원 |
| 무료배송 기준 | 3만 원 이상 무료, 미만 시 배송비 2,500원 |
| 무료배송 안내 | 장바구니에 무료배송까지 남은 금액 표시 |

- 매장은 필요한 상품을 즉시 소량 구매, 온라인은 여러 상품을 모아 한 번에 구매하는 경향
  -> 온라인 객단가가 매장보다 높음

### 비용 구조

| 항목 | 내용 |
|---|---|
| 주문 1건당 물류비 | 약 3,500원 (택배 3,000원 + 포장 500원) |
| 반품 회수 비용 | 건당 약 3,000원 (플랫폼 부담) |

### 카테고리별 상품 마진율

| 카테고리 | 마진율 |
|---|---|
| 스킨케어 | 40% |
| 색조 | 45% |
| 헤어·바디 | 30% |
| 위생용품 | 20% |
| 건강기능식품 | 35% |
| 기타 | 30% |

### 주문 공헌이익 (사내 기준)

- 주문 공헌이익 = 상품 매출 × 마진율 + 배송비 수입 − 물류비 − 반품 회수 비용

### 배송 정책 변경 이력

| 시점 | 변경 | 사유 |
|---|---|---|
| 올해 초 | 무료배송 기준 2만 원 → 3만 원 | 택배·포장 비용 상승으로 주문당 물류비 증가, 2만 원대 무료배송 주문의 수익성 악화 |

### 카테고리별 온라인 매출 비중 

|카테고리 | 비중 |
|---|---|
| 스킨케어 | 35% |
| 색조 | 20% |
| 헤어·바디 | 15% |
| 위생용품 | 12% |
| 건강기능식품 | 10% |
| 기타 | 8% |


## 5. 멤버십

| 항목 | 내용 |
|---|---|
| 가입 | 매장 또는 온라인에서 가입, 하나의 회원 ID로 통합 |
| 적립 | 매장·온라인 구매 모두 적립 |
| 등급 | 최근 3개월 구매 금액 기준 4단계 ( 펄 / 골드 / 다이아몬드 / 블랙 다이아몬드 ) |

## 6. 앱 화면 구성

```
홈 → 상품 탐색(검색·카테고리) → 상품 상세 → 장바구니 → 주문서 → 결제 완료
```

| 화면 | 주요 구성 |
|---|---|
| 상품 상세 | 상품 정보, 옵션(호수·컬러·용량) 선택, 리뷰 |
| 장바구니 | 담은 상품, 무료배송까지 남은 금액, 구매하기 |
| 주문서 | 배송지 입력, 결제수단 선택, 약관 동의 (저장된 정보가 있으면 자동 입력) |
| 결제 | 카드, 간편결제 |

## 7. 분석 데이터 범위

| 항목 | 내용 |
|---|---|
| 데이터 | 앱 방문 회원 중 무작위 샘플 (전체 규모의 일부) |
| 환경 | BigQuery (원본 → 정제 → 마트), Python은 통계 검정·시각화 |
| 이벤트 로그 형식 | GA4 BigQuery 내보내기 형식 |
